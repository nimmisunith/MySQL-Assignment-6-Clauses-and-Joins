This assignment demonstrates the use of MySQL queries to 
retrieve, filter, sort, group, and analyze employee data.
It covers important SQL concepts such as
DISTINCT, aliases, WHERE, UPDATE, ORDER BY, LIMIT, aggregate functions, GROUP BY, HAVING, and 
different types of JOINs including INNER JOIN, LEFT JOIN, and RIGHT JOIN. 
The assignment uses the employee database created in Assignment 1 and
provides practical experience in working with relational data using MySQL Workbench.
